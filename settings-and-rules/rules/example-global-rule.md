# Secrets

- Never print, repeat or paste the value of an API key, password or token: not in chat, not in a file, not in a commit. Refer to a key by its NAME only, for example EMAIL_SERVICE_API_KEY.
- When a key is needed, tell me its NAME and which project's .env file it belongs in, and let me add the value myself.
- Never copy a .env file, or any value from one, into another folder or another client's project.
