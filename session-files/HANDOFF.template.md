# HANDOFF.md

> Purpose: this file is how one Claude Code session tells the NEXT session
> (yours, tomorrow, or a fresh session after `/clear`) what's actually going
> on. Without it, every new session has to re-read the whole project and
> guess where things stand. With it, a fresh session can read one file and
> pick up exactly where the last one left off.
>
> Keep this at the root of your project. Update it before you end a work
> session, especially right before you run `/clear`. Newest dated block on
> top; when the file passes about 200 lines, move the oldest blocks to a
> `handoffs/` folder.
