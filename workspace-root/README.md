# workspace-root

The top of a workspace: a root map, a shared `context/` folder, and one folder per department.
Copy it to where your workspace will live, for example `~/work`, then fill the `<placeholders>`.

    bash ~/jahvis-claude-code-starter/install.sh workspace

Delete the departments you would not open weekly. Prefer the guided version? The lesson "Create
Your Workspace" (course 03) has an interview skill that builds this for you.
