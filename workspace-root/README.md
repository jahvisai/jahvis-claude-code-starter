# workspace-root

The top of a workspace: a root map, a shared `context/` folder, and one folder per department.
Copy it to where your workspace will live, for example `~/work`, then fill the `<placeholders>`.

    bash ~/jahvis-claude-code-starter/install.sh workspace

Delete the departments you would not open weekly.

Prefer the guided version? Open the `jahvis-claude-code-starter` folder in Claude Code and type
`/jah-setup-interview`. It asks at most seven questions, saves each answer, then fills `AGENTS.md`,
`context/` and `connections.md` for you.

Also in here: `connections.md` (which tool each business area uses), `decisions/log.md` (dated
decisions, added to and never edited) and the `/jah-grill` skill in `.claude/skills/` (Claude
interviews you about a plan and saves every answer).
